# Портал бизнес-центра «Меридиан»

Кликабельное демо по DEMO-SPEC.md. Данные вымышленные: демонстрационная смена 24 ноября 2026, 10:00.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:4180/. Плавающая кнопка «+» открывает демопульт с четырьмя ролями, темами, переходами и подтверждаемым сбросом.

- Дарья создаёт обращение. Мария назначает инженера и отвечает в карточке. Дарья и Тимур видят изменения в своих областях доступа.
- Дарья приглашает гостя. Игорь ищет номер на посту и отмечает вход и выход. Отзыв запрещает вход, но не мешает отметить выход, если гость уже внутри.
- Дарья бронирует «Орион» с 12:00 до 13:00. Занятость видна Тимуру и диспетчеру. При отмене слот возвращается в расписание, а запись сохраняется.

Состояние и оформление хранятся в localStorage. Разрешения показывают сценарий продукта в интерфейсе.

В демо используются фотографии разных объектов. [Источники и лицензии фотографий](public/photo-credits.html).

`npm run build` собирает статический сайт в `dist/`.
